# Site Institucional - MS Distribuidora

Estrutura de arquivos pronta para hospedagem (cPanel, Hostinger, Vercel, Netlify, etc.):

- `index.html`: Página principal com todas as seções (Início, Diferenciais, Produtos, Sobre Nós, Depoimentos e Contato).
- `css/style.css`: Folha de estilos completa, responsiva e sem dependências externas.
- `js/script.js`: Script para navegação suave entre as seções da página.
