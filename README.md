# Site Institucional - MS Distribuidora RS

Pacote completo pronto para hospedagem (HTML5, CSS3 e JavaScript puro):

- `index.html`: Página principal com o conteúdo institucional de msdistribuidorars.com.br, diferenciais, categorias de produtos, Missão/Visão/Valores, depoimentos e formulário integrado ao WhatsApp.
- `style.css`: Identidade visual com paleta laranja (#F5820D) e grafite/preto (#232323) alinhada à logomarca.
- `script.js`: Menu responsivo para dispositivos móveis e redirecionamento do formulário para o WhatsApp (51) 99136-4247.
- `assets/logo-ms-distribuidora.svg`: Logomarca vetorial em alta definição (pode ser substituída pelo arquivo PNG original mantendo o nome ou atualizando o caminho no HTML).

## Como publicar
Basta extrair o arquivo `.zip` e enviar todos os arquivos e a pasta `assets/` para a raiz (`public_html` ou `www`) da sua hospedagem.
